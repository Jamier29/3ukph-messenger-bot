3UK Philippines Partner API

Order eSIMs automatically from your website or booking system. Version 1.

Overview

The API lets your system list our eSIM plans with your partner prices, place orders that are paid from your prepaid partner wallet, and receive the eSIM QR code right away.

Base URLhttps://3ukph.com/partner/v1
FormatJSON over HTTPS. Prices are in Philippine pesos (PHP).
AuthHeader Authorization: Bearer YOUR_API_KEY
Limits60 requests per minute. A daily order limit applies per partner (see /me).

Keep your API key secret and use it only from your server, never in a web page or mobile app. If it leaks, ask us to replace it.

Quick start

  1. Get your API key from 3UK Philippines and top up your partner wallet.
  2. Call GET /plans and save the planId of the plans you sell.
  3. When a guest buys, call POST /orders with the planId and your own order number as reference.
  4. Show or email the returned QR code (esim.qrCodePng) to your guest.

Endpoints

GET/me

Your account, wallet balance and daily order limit.

curl https://3ukph.com/partner/v1/me -H "Authorization: Bearer YOUR_API_KEY"

{ "partner": "TripHappy", "tier": "partner", "walletBalancePHP": 5000, "dailyOrderLimit": 50 }

GET/plans

All plans you can order, with your price. Optional filters: destination (e.g. Japan; also matches regional plans that cover it) and type (country or regional).

curl "https://3ukph.com/partner/v1/plans?destination=Japan" -H "Authorization: Bearer YOUR_API_KEY"

{ "currency": "PHP", "count": 48, "plans": [
  { "planId": "pl_3f9a1c2b7d10", "destination": "Japan", "type": "country",
    "name": "10GB eSIM Data for 7 Days for Japan", "data": "10GB", "unlimited": false,
    "validityDays": 7, "countries": ["Japan"], "suggestedRetailPHP": 421.2, "pricePHP": 361 } ] }

pricePHP is what you pay. suggestedRetailPHP is our public price; you may set your own selling price. Refresh the list daily, as prices can change.

POST/orders

Places an order, pays it from your wallet and issues the eSIM. Usually takes 5 to 40 seconds, so set your HTTP timeout to at least 90 seconds.

FieldRequiredDescription
planIdyesFrom GET /plans.
referenceyesYour unique order id (letters, numbers, . _ : -, max 64). Sending the same reference again never creates a second order; it returns the first result.
expectedPricePHPnoIf set and the price has changed, the order is refused (409) instead of charging a different amount.
customerName, customerEmailnoFor your records and our support team.
curl -X POST https://3ukph.com/partner/v1/orders \
  -H "Authorization: Bearer YOUR_API_KEY" -H "Content-Type: application/json" \
  -d '{ "planId": "pl_3f9a1c2b7d10", "reference": "TH-100045", "expectedPricePHP": 361,
        "customerName": "Juan Dela Cruz" }'

201 Created

statusMeaning
completedThe eSIM is ready. Send the QR code to your guest.

GET/orders/{reference}

Returns a saved order, including the eSIM details. Use it if your request timed out, before retrying.

GET/esims/{iccid}/usage

Data used and remaining for an eSIM ordered through your account.

Errors

HTTPWhen
400Missing or invalid field (for example an unknown planId).
401 / 403Wrong API key, or the partner account is not active.
402Not enough wallet balance. Nothing was charged.
409Price changed, plan unavailable, or the same order is already processing.
429Too many requests or the daily order limit was reached.
5xxTemporary problem. Check GET /orders/{reference} before retrying.

Every error body is { "error": "message" }.

Installing the eSIM

Guests should install the eSIM before travelling, while on Wi-Fi: scan the QR code in Settings › Mobile/Cellular › Add eSIM, or enter smdpAddress and activationCode manually. At the destination they turn on the eSIM line and data roaming. The phone must be eSIM-compatible and network-unlocked.
